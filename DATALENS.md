# Дашборд в Yandex DataLens — пошаговая сборка

Дашборд строится из CSV-витрин в папке [`marts/`](marts). Все формулы совпадают со [словарём метрик](METRICS.md).
Сборка занимает около часа. Названия кнопок в интерфейсе DataLens со временем меняются; если какой-то кнопки
нет на месте, ищите ближайшую по смыслу — порядок действий тот же.

**Что получится:** дашборд «Метрики интернет-магазина» из трёх вкладок — «Обзор», «Почему изменилась выручка»,
«Клиенты» — и публичная ссылка на него для README и резюме.

## 0. Подготовка

1. Откройте [datalens.yandex.ru](https://datalens.yandex.ru) и войдите Яндекс-аккаунтом.
2. Создайте папку `online-retail-metrics` — в неё будут складываться подключения, датасеты, чарты и дашборд.
3. Скачайте файлы из [`marts/`](marts): `orders.csv`, `customers.csv`, `cohorts.csv`, `bridge.csv`, `factors.csv`
   (на GitHub: файл → кнопка «Download raw file»).

## 1. Подключение «Файлы»

**Создать → Подключение → Файлы**, загрузите все пять CSV в одно подключение и сохраните его как
`retail_files`. Для каждого файла проверьте разбор: разделитель — запятая, кодировка — UTF-8, первая строка — заголовки.

Проверьте типы полей (DataLens угадывает их сам, но не всегда верно):

| Файл | Поле | Тип |
|---|---|---|
| orders.csv | `invoice_date` | Дата и время |
| orders.csv | `month`, `cohort_month` | Дата |
| orders.csv | `customer_id`, `invoice` | **Строка** (иначе DataLens посчитает сумму ID) |
| orders.csv | `is_cancellation`, `items`, `lines` | Целое число |
| orders.csv | `revenue` | Дробное число |
| customers.csv | `customer_id` | Строка |
| customers.csv | `first_purchase`, `last_purchase`, `cohort_month` | Дата |
| cohorts.csv | `cohort_month` | Дата |
| cohorts.csv | `retention` | Дробное число |

## 2. Датасеты и вычисляемые поля

Создайте четыре датасета из подключения `retail_files` (**Создать → Датасет**, перетащите таблицу из списка).

### `ds_orders` (orders.csv)

Добавьте вычисляемые поля (**+ Поле**):

| Поле | Формула | Формат |
|---|---|---|
| Выручка | `SUM([revenue])` | число, 0 знаков, разделитель разрядов |
| Валовая выручка | `SUM_IF([revenue], [is_cancellation] = 0)` | число |
| Доля отмен | `-SUM_IF([revenue], [is_cancellation] = 1) / SUM_IF([revenue], [is_cancellation] = 0)` | процент, 1 знак |
| Заказы | `COUNTD(IF [is_cancellation] = 0 THEN [invoice] END)` | число |
| Клиенты | `COUNTD(IF [is_cancellation] = 0 THEN [customer_id] END)` | число |
| Средний чек | `[Выручка] / [Заказы]` | число, 0 знаков |
| Заказов на клиента | `COUNTD(IF [is_cancellation] = 0 AND [customer_id] IS NOT NULL THEN [invoice] END) / [Клиенты]` | число, 2 знака |

### `ds_customers` (customers.csv)

| Поле | Формула |
|---|---|
| Клиентов | `COUNTD([customer_id])` |
| Выручка клиентов | `SUM([revenue])` |

### `ds_cohorts` (cohorts.csv)

| Поле | Формула | Формат |
|---|---|---|
| Удержание | `AVG([retention])` | процент, 0 знаков |

### `ds_bridge` (bridge.csv) и `ds_factors` (factors.csv)

Вычисляемые поля не нужны. В `ds_factors` поставьте полю `change_pct` формат «процент, 1 знак».

**Проверка после шага 2:** в превью `ds_orders` с фильтром `period = Год 2` поле «Выручка» должно дать
9 330 523, «Клиенты» — 4 293, «Заказы» — 18 957 (вместе с заказами без ID).

## 3. Чарты

**Создать → Чарт**, выберите датасет, затем тип визуализации. Названия чартов ниже — сразу с выводом:
так дашборд читается без пояснений.

### Вкладка «Обзор» — датасет `ds_orders`

1. **Пять индикаторов** (тип «Индикатор»): «Выручка», «Заказы», «Клиенты», «Средний чек», «Доля отмен» —
   по одному показателю в каждом.
2. **«Рост выручки дали продажи без ID и новые клиенты»** — «Диаграмма с областями» (накопительная):
   X — `month` (группировка «Месяц»), Y — «Выручка», Цвета — `customer_type`. Фильтр: `period` ≠ «Дек 2011 (неполный)».
3. **«Великобритания стоит на месте, растут Европа и Австралия»** — «Столбчатая диаграмма»: X — `region`,
   Y — «Выручка», Цвета — `period`. Фильтр как в п. 2.
4. **«Сезонность: ноябрь почти втрое выше февраля»** — «Линейная диаграмма»: X — `month`, Y — «Выручка».

### Вкладка «Почему изменилась выручка»

5. **«Ушедшие клиенты стоили 1,02 млн — новые это перекрыли»** — «Столбчатая диаграмма» по `ds_bridge`:
   X — `step`, Y — `value` (сумма), Цвета — `sign` (Итог — серый, Рост — зелёный, Падение — красный).
   Сортировка по `step_order` по возрастанию.
6. **«Главный фактор падения — частота покупок»** — «Таблица» по `ds_factors`: `factor`, `before`, `after`,
   `change_pct`, `contribution`. В настройках столбца `contribution` включите заливку «Столбик» (bar) —
   отрицательные вклады станут видны сразу.

### Вкладка «Клиенты»

7. **«Через месяц возвращается каждый пятый новый клиент»** — «Сводная таблица» по `ds_cohorts`:
   Строки — `cohort_month` (формат «Месяц»), Столбцы — `month_number`, Показатели — «Удержание»,
   Цвета — «Удержание» (градиент). Фильтры: `month_number` ≤ 12, `cohort_month` > 01.12.2009
   (первая когорта — вся накопленная до начала данных база, а не новые клиенты).
8. **«27 % клиентов дают 74 % выручки»** — «Столбчатая диаграмма» по `ds_customers`: X — `segment`,
   Y — «Выручка клиентов»; второй чарт рядом с Y — «Клиентов».
9. **«Список на реактивацию»** — «Таблица» по `ds_customers`: `customer_id`, `country`, `segment`, `orders`,
   `revenue`, `revenue_y1`, `revenue_y2`, `last_purchase`, `recency_days`. Фильтр: `segment` в
   («Нельзя потерять», «Под угрозой»), сортировка по `revenue` по убыванию.

## 4. Дашборд

1. **Создать → Дашборд** `Метрики интернет-магазина`, добавьте три вкладки.
2. Разложите чарты по вкладкам, как в п. 3. Индикаторы — одной строкой сверху.
3. На вкладке «Обзор» добавьте **Селекторы** по `ds_orders`: `period` (значение по умолчанию — «Год 2»)
   и `region` (множественный выбор). Селекторы действуют на чарты 1–4.
4. Под заголовком каждой вкладки добавьте **Текст** — одно предложение вывода из
   [записки](https://alex91132.github.io/online-retail-metrics/), например для «Обзора»: «Выручка года 2 выросла на 1,9 %,
   но выручка клиентов с ID упала на 2,0 %: рост дали заказы без ID и заграница».

## 5. Публикация

1. В дашборде: меню **…** → **Публичный доступ** (или «Поделиться → Опубликовать»). DataLens предложит
   опубликовать вместе с дашбордом его чарты и датасеты — согласитесь: данные открытые (CC BY 4.0).
2. Скопируйте публичную ссылку и пришлите — она пойдёт в README, на страницу проекта и на сайт.
3. Сделайте скриншот вкладки «Обзор» — он станет превью карточки на сайте.

Если какой-то шаг не получается, пришлите скриншот — поправлю инструкцию.
